03 / 사용 방법 & 검증 정보

짧은 확인 방법 4줄

  1. 위치 — 공개 게임 페이지의 상단 플레이 영역으로 이동한다.
  2. 행동 — ‘방어 시작’을 선택한 뒤 경고 패킷만 클릭하여 30초 동안 서버를 방어한다.
  3. 통과 기준 — 30초 생존 시 ‘방어 성공’과 해당 판의 결과 기록이 표시된다.
  4. 실패 상태 — 무결성이 0%가 되면 ‘서버 침해’와 놓침·오차단 횟수가 표시된다.

새 게임 시작 시 점수·시간·체력·패킷은 초기화된다. A/B/C 비교 기록·효과 설정·최종 판단은 브라우저에 보존된다. 자유 플레이 기록은 최근 500판까지 보관되며 비교 기록에는 포함되지 않는다. 최종 난이도를 저장하면 이후 플레이에 해당 설정이 적용된다. 빈 저장값 또는 손상된 저장값은 기본값으로 복구된다. 창이 비활성화되면 게임은 자동으로 일시정지되며 수동으로 재개할 수 있다.
