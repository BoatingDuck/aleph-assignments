DOCUMENTATION

분석 가이드.

입력 형식과 탐지 규칙, 재현 방법을 확인하세요.

01 / DATA INGESTION

로그 가져오기

최대 2MB, 4,000행의 CSV 또는 JSON을 분석합니다. 유효하지 않은 시간값을 가진 행은 제외하며 그 개수를 안내합니다.

timestamp,ip,username,path,status,method,message
2026-11-06T03:00:00Z,203.0.113.9,admin,/login,401,POST,invalid password

JSON은 객체 배열 또는 {"events": [...]} 형태를 지원합니다. 시간값은 ISO 8601 사용을 권장합니다.

02 / DETECTION RULES

탐지 규칙

동일 이벤트가 여러 규칙에 해당하면 사건이 중복 집계될 수 있습니다. 임계값 도달은 공격 확정이 아니라 조사 시작 신호입니다.

03 / VERIFICATION

3단계 확인 방법

  1. 대시보드에서 합성 샘플의 탐지 사건 4종을 확인합니다.
  2. 탐지 사건을 열고 근거 로그를 확인한 뒤 상태·메모를 저장합니다.
  3. 사건 보고서를 내보내고, 원본 이벤트 검색과 CSV 가져오기를 확인합니다.
04 / PRIVACY

로컬 처리 및 주의사항

로그 분석은 서버 API 호출 없이 이 브라우저에서만 실행됩니다. 가져온 데이터와 조사 메모는 브라우저의 로컬 저장소에 보관되며, 저장 용량 제한에 도달하면 현재 세션에서만 유지될 수 있습니다.

공용 PC에서는 사용 후 로컬 데이터 삭제를 실행하세요. 실사용 로그에 비밀번호, 토큰 등 비밀정보를 넣지 마세요.
