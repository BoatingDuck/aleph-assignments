# 최종 제출 — 작성용 초안

> 이 문서는 최종 제출 버튼을 누른 기록이 아닙니다. Workbench에서 2차 점검이 접수되고 최종 제출란이 열리면 사용하세요.

## 프로젝트 한 줄 설명

브라우저에서 CSV·JSON 보안 로그를 분석하고 규칙 기반 이상 징후를 탐지해 사건 조사와 대응 기록까지 관리하는 웹앱입니다.

## 실제 완성한 기능

- 최대 2MB/4,000행 CSV·JSON 로그 입력 및 4종 탐지 규칙
- 탐지 근거 확인, 위험도 분류, 조사 상태 3종, 메모 저장/복원
- 이벤트 시각화/검색, 사건 보고서(Markdown), CSV 다운로드, 모바일 대응
- 처음 열 때 150건 합성 로그로 동작을 시연할 수 있으며 서버 설정이나 로그인 불필요

## 재현 통과 확인 (3단계)

1. `https://shieldlog-premium.vercel.app/` 접속 → 이벤트 150건·탐지 사건 4개 표시 확인.
2. 사건 열기 → 근거 로그 확인·상태/메모 저장 → 새로고침 후 유지 확인.
3. 보고서 다운로드 → 원본 이벤트 검색 → CSV 가져오기 정상 동작 확인.

## AI와 나의 판단 3줄

AI에게 기획 정리, 탐지 규칙과 인터페이스 구현, 파일 입출력, 테스트, 배포와 제출 문서 초안 작성을 맡겼습니다.
저는 프로젝트의 방향을 보안 이벤트 탐지·분석으로 선택하고, 실제로 확인할 수 있는 기능을 기준으로 삼았습니다.
이상 징후 탐지는 침해 확정과 다르므로 오탐 가능성과 로컬 저장의 한계를 명시하고 최종 결과를 판단합니다.
