# ShieldLog 가독성·모션 개선 (2026-11-06)

## 사용자 요청
기존 화면의 정돈된 정보 구조를 유지하고 작은 텍스트를 더 읽기 쉽게 확대하며, 제한적 애니메이션을 추가했다.

## 구현 변경
- 10~12px이던 표·탐지 항목·버튼·부가 설명 등의 텍스트를 대체로 12~14px로 올렸다.
- 본문 15px, 표 데이터 13px, 안내·가이드 본문 14px, 주요 카드 설명 12px, 사건명 14px, 위험도 레이블 12px로 조정했다.
- 설명용 글씨의 대비를 강화했다. 다크 네이비/청록 팔레트는 보존했다.
- 화면 전환, 통계 카드의 순차 등장, 차트 라인 드로잉, 버튼 반응, 모달·사건 상세 진입에 모션을 적용했다.
- 740px 이하 모바일 전용 크기를 별도로 조정해 표·카드·네비게이션의 레이아웃을 보호했다.
- `prefers-reduced-motion` 설정을 존중해 모션을 비활성화한다.

## 범위
탐지 엔진, 규칙 임계값, 개인정보 처리, 파일 크기 제한, 조사 기록 로직은 변경하지 않았다.

## 검증
수정 후 자동 탐지 테스트와 Chromium 브라우저 경로별 기능·스크롤·폰트·모션 검사를 수행한다. 이 문서의 검증 항목은 실행 보고서에서 확인한다.
