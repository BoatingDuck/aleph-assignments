# 중간 점검 2차 — 작성용 초안

> Workbench에서 중간 점검 1차가 접수된 뒤 열리는 양식에 작성하세요. 접수·통과가 이미 되었다는 의미가 아닙니다.

## 이번에 만든 것

CSV/JSON 파일 가져오기와 유효하지 않은 시간값 제외 안내를 구현했습니다. 탐지 사건별 조사 상태 3종 및 조사 메모를 브라우저 저장소에 기록하고, 새로고침 후에도 유지되도록 했습니다. 사건 Markdown 보고서와 원본 CSV 다운로드, 원본 이벤트 검색 및 페이지 이동, 모바일 반응형 메뉴를 구현했습니다.

## 확인하는 방법 — 3단계 이내

1. 결과물 주소에서 **탐지된 사건**을 열고 임의의 사건에 `조사 중` 상태와 메모를 저장한 뒤 새로고침합니다.
2. 상태와 메모가 유지되는지 확인하고 **사건 보고서 내보내기**를 실행합니다.
3. **원본 이벤트**에서 IP를 검색하고 **로그 가져오기**로 `examples/synthetic-events.csv`를 불러옵니다.

## 바뀐 점과 이유

이벤트를 보는 것에서 끝나지 않고 실제 분석 흐름을 재현하도록 조사 메모·상태·보고서 기능을 추가했습니다. 서버 계정 없이 시험할 수 있도록 브라우저 저장과 다운로드 방식을 유지했습니다.

## AI에게 맡긴 일과 내가 판단한 일

AI에게 사건 관리 UI, 로컬 저장, 가져오기·내보내기, 모바일 화면 구현과 브라우저 검증을 맡겼습니다. 보안 이벤트 분석이라는 원래 목표를 유지할지 검수하고, 중간 점검 내용과 최종 제출 여부는 직접 판단합니다.
