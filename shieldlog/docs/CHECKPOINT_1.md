# 중간 점검 1차 — 작성용 초안

> 실습 화면의 중간 점검을 자동 접수한 기록이 아닙니다. 아래 내용을 실제 Workbench 1차 점검란에 옮겨 적고 제출자가 확인해야 합니다.

## 이번에 만든 것

합성 샘플 보안 로그 150건을 자동 생성하고, 반복 로그인 실패·다중 계정 인증 시도·민감 경로 탐색·HTTP 4xx 급증 등 4가지 규칙을 구현했습니다. 대시보드의 이벤트 집계, 위험도, 고유 출발지 IP, 시간대별 이벤트 그래프, 탐지 사건 목록이 입력 로그와 연결되도록 구현했습니다.

## 확인하는 방법 — 3단계 이내

1. 결과물 주소 `https://shieldlog-premium.vercel.app/`로 접속합니다.
2. 첫 화면에서 총 150건, 탐지 사건 4개, 높은 위험 2개, IP 9개를 확인합니다.
3. **탐지된 사건**을 열고 4종 탐지 유형과 사건별 근거 로그가 표시되는지 확인합니다.

## 바뀐 점과 이유

실제 서버와 직접 연결하는 방식 대신 CSV/JSON 파일 및 합성 샘플을 사용하는 브라우저 로컬 분석으로 범위를 조정했습니다. 운영 서버 계정이나 민감 데이터를 요구하지 않고 채점자가 기능을 같은 조건에서 재현할 수 있도록 하기 위해서입니다.

## AI에게 맡긴 일과 내가 판단한 일

AI에게 탐지 규칙 설계, 로그 정규화, 샘플 로그 생성, 대시보드 구현 및 테스트를 맡겼습니다. 프로젝트 주제는 보안 이벤트 분석 앱으로 직접 선택했고, 실제 결과를 검수한 뒤 점검 제출 여부를 판단합니다.

## 다음에 할 일
