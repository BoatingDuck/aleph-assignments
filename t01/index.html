상황
3인 팀으로 학술제용 LMS 연동 학습 지원 시스템을 개발 할 때, 팀원마다 익숙한 기술과 구현 역량이 다른 상황이었습니다.
행동

상황

결과
해당 실습의 VLAN 1에서는 기본 우선순위 0에 VLAN ID 1이 반영되어 1로 표시된다는 것을 이해할 수 있었습니다.
