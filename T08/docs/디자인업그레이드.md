# T08 디자인 업그레이드 — 가을색 × 인터랙티브 Bento

> **디자인 개발 이력:** 이 문서는 당시 디자인 변경안을 기록한 것으로, 아래 실행 안내는 과거 적용 단계의 절차입니다. 현재 T08은 [최종 README](../README.md)와 [검사 결과](검사결과_2026-10-21.md) 기준으로 배포·인증 검증을 마쳤습니다.

## 콘셉트

기존 T01의 크림색, 브라운, 테라코타, 올리브 컬러를 유지하면서 화면을 ‘기본 HTML’보다 깊이감 있는 포트폴리오처럼 다듬었습니다. 기존 소개 내용·프로젝트 본문·공개 범위를 삭제하거나 다른 내용으로 변경하지 않았습니다.

- 큰 타이포그래피와 반투명 Hero 카드, 부드러운 배경 조명
- 세 가지 강점을 비대칭 Bento 카드로 구성
- 프로젝트를 잡지처럼 읽히는 카드로 구성
- 천천히 흐르는 장식형 텍스트 띠, 스크롤 등장, 상단 진행선, 현재 섹션 표시, 포인터 조명 효과
- 모바일 세로 레이아웃 및 `prefers-reduced-motion` 지원
- 잠긴 패스키 자리도 같은 색감과 둥근 카드 형태로 구성

## 적용 방법

기존 `aleph-t08-work/T08` 폴더에 패치의 `T08` 폴더를 덮어씁니다. 이어서:

```powershell
cd C:\Users\User\Desktop\aleph-t08-work\T08
npm.cmd run sync:t01
npm.cmd run build
npm.cmd test
```

`sync:t01`이 `public/index.html`에 디자인 CSS/JS 링크를 다시 생성하므로, **수정 후 반드시 실행**합니다. 기존 `T01` 폴더를 수정하지 않습니다.

변경된 파일: `public/design.css`, `public/design-motion.js`, `scripts/sync-t01.mjs`, `tests/structure.test.mjs`, 이 문서. 마지막으로 합성된 `public/index.html`이 변경됩니다.

## 보호 영역 관련 확인

디자인 전용 JS는 공개 화면에만 효과를 적용합니다. 패스키 등록·로그인·로그아웃·DB·서명 검증 관련 코드는 수정하지 않았습니다. 로그인되지 않은 HTML에서 비공개 메모를 미리 넣거나 렌더링하지 않습니다. 따라서 애니메이션 구현 때문에 API 보호가 약해지지는 않습니다.

**별도 실행 확인이 필요한 사항:** 실제 패스키 로그인 및 Supabase/Vercel 배포는 시각적 렌더링 테스트와 다르므로 기존 T08 검증 가이드대로 별도 확인합니다.
