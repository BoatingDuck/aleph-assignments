# T08 디자인 v6 — 시선 집중형 인터랙티브 개편

> **v6 디자인 변경 이력:** 당시 파일 적용·테스트 범위를 보존한 문서입니다. v6의 테스트 개수와 배포 전 안내는 최신 제출 상태를 말하지 않습니다. 최신 자동 테스트는 **31/31 PASS**이며 실제 패스키·서버 실측도 별도로 완료했습니다.

## 변경 의도
- **v5의 문제:** 제목이 지나치게 크고, 소개/강점이 양쪽으로 흩어져 첫 화면을 한 번에 읽기 어려웠으며 움직임이 약했습니다.
- **v6 목표:** 따뜻한 크림·브라운 톤 유지, 타이포 크기 축소, 중앙 집중 배치, 풍부하지만 차분한 실제 인터랙션.

## 실제 구현
1. 첫 화면의 기존 제목은 유지하고 글자 크기를 최대 52px로 줄였습니다. 제목을 두 줄로 유지하되 가운데 정렬합니다.
2. 소개, 행동 버튼, 논문 링크를 한 중심축에 모았습니다. 기존 긴 소개 문장은 '소개 자세히'에 보존됩니다.
3. 세 가지 강점은 PC에선 가로 3칸, 모바일에선 세로 3칸이며, 기존 텍스트·링크가 유지됩니다.
4. 시작 장면: 제목 줄 단위 리빌, 강조 밑줄의 전개, 부드러운 지연 등장 효과.
5. 상호작용: 느리게 움직이는 라인 오브젝트, 마우스 위치에 반응하는 주변빛, 강점 카드의 부드러운 부상/빛, 스크롤 진행선, 섹션 스크롤 리빌.
6. `prefers-reduced-motion` 사용 시 장식 애니메이션은 정지하고 정보는 계속 보입니다. 키보드 포커스/원래 자세히 보기 기능은 유지합니다.

## 파일 관계 및 과제 안전
- `public/design.css`: 디자인 오버라이드 (원본 T01 스타일 파일은 수정하지 않습니다).
- `public/design-motion.js`: UI 동작만 변경 (패스키 인증 상태나 서버 API는 호출하지 않습니다).
- `scripts/sync-t01.mjs`: T01 HTML/CSS/JS 원본을 복사한 뒤 추가 디자인 파일을 연결합니다.
- `tests/structure.test.mjs`: 원본 보존 및 UI 검사 추가.
- `api/`, `lib/`, `src/passkey-client.js`, `snippets/private-room.html`은 수정하지 않습니다.

## 기존 GitHub T08에 v6 적용 (아직 v4/v5를 적용하지 않았더라도 가능)
1. **전체 ZIP이 아니라 v6 디자인 패치 ZIP**을 다운로드합니다.
2. `C:\Users\User\Desktop\aleph-t08-work` 저장소 루트에 풀어서 `T08/` 내용을 병합합니다.
3. PowerShell에서 다음 순서로 실행합니다.

```powershell
cd C:\Users\User\Desktop\aleph-t08-work\T08
npm.cmd run sync:t01
npm.cmd run build
npm.cmd test
```

4. 먼저 `T08_v6_애니메이션체험판.html`을 브라우저에서 열어 디자인을 확인한 뒤, 마음에 들면 GitHub 커밋/배포를 진행합니다.
