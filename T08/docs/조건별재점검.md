## 실측 방법에 관한 주석

- **아이폰으로 수행한 일:** 암호 앱에 등록된 실제 패스키 확인, QR 스캔·인증 승인, PC 자동 로그인과 모바일 비공개 메모 조회.
- **Chrome 가상 인증기로 수행한 일:** 시험용 패스키 생성, 등록 응답 Network 확인, 유효·변조 서명 비교(200/403), 동일 인증 응답 재전송(409), 삭제된 credential ID 검증(403).
- **자동 테스트:** Node.js 22 / 31개 통과. 코드를 읽어 규칙을 확인하는 검사와 모의 서명을 이용한 테스트가 포함되지만, 실제 운영 HTTP 실측을 대체하지 않습니다.
- **미보관 증빙:** C03 시크릿 창 별도 캡처, C20 두 등록 질문 원문 나란히 캡처, C22 전체 공개키 출력, C23 등록 요청의 모든 접힌 하위 필드 캡처, C40 URL·본문 위조 응답 캡처, C46 키 0개 시나리오. 해당 항목은 **미구현이라고 단정하지 않고 구현·DB 확인과 실측 근거를 분리**했습니다.
