## 점검 시 주의

- **테스트 11개 통과는 정적·순수 함수 검사이지 실기기 패스키 성공/거절 실증이 아닙니다.** 공개키 DB 값, challenge 2회 비교, 등록 취소, 실제 요청과 HTTP 응답 등은 여기서 확인할 수 없었습니다.
- `npm install`은 이 검토 실행 환경에서 DNS 연결이 불가능해 완료되지 않았습니다. 따라서 브라우저 번들 생성 및 Vercel 빌드 성공은 확인하지 못했습니다.
- 현 시점에는 URL 배포도 하지 않았고 DB 초기화나 패스키 등록도 실행하지 않았습니다. `docs/인증구현설명서.md`의 `[실측 입력]`을 남김없이 채워야 합니다.
- 임시 등록 초대 링크와 DB 연결 문자열·세션 쿠키는 절대 GitHub 또는 제출 증빙에 넣지 마세요.
