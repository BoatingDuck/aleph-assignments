## 검사 재현 방식의 구분

실제 아이폰은 QR 스캔·패스키 승인·PC 자동 로그인에 사용했습니다. 반면, 서명의 한 비트 변조나 성공한 JSON 그대로 재전송하는 검사는 모바일 UI에서 수행하기 어려웠기 때문에 **PC Chrome WebAuthn 가상 인증기에서 시험용 패스키를 별도 등록**하여 실제 운영 서버에 요청했습니다. 이는 단순한 정적 테스트가 아니며, **아이폰에서 변조를 실행했다는 뜻도 아닙니다.**

**완료 증거는 완료로, 별도 캡처가 남지 않은 경우는 보완 가능 항목으로** 구분했습니다. 구체적으로 C03 시크릿 창 캡처, C20 질문 원문 2개 화면, C22 공개키 전체 출력, C23 접힌 Payload 일부, C40 위조 요청 캡처, C46 키 0개 경우는 수행했다고 주장하지 않습니다.
