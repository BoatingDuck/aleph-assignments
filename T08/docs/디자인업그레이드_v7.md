## 이번 수정 범위

이 패치는 기존 T01 소개 내용을 삭제하거나 T08 WebAuthn 등록·로그인·DB·세션 코드를 수정하지 않습니다. `design.css`, `design-motion.js`, `sync-t01.mjs`, 회귀 테스트만 변경했습니다.

1. **프로젝트 2개 카드**: 마우스 호버 때 `padding-left: 9px`로 내용이 옆으로 이동하던 규칙을 무효화했습니다. 기본 상태와 호버 상태 모두 가로 패딩 `clamp(23px,3.1vw,38px)`을 유지합니다(모바일 18~20px). 색만 약 0.85초에 걸쳐 전환합니다.
2. **전체 움직임**: 호버 시 강점 카드 위로 5px 이동, 강점 행 옆으로 9px 이동, 버튼 위로 이동하는 동작을 제거했습니다. 대신 배경·테두리·그림자·색상 전환에 완만한 이징을 적용하고, 첫 화면의 등장/스크롤 등장은 약 1.1~1.3초로 조정했습니다. 첫 화면 마우스 위치에 따라 움직이는 빛은 JS 보간으로 더 매끄럽게 유지합니다.
3. **첫 화면의 강점 카드 3개**: 카드 링크의 `min-height:84px`을 해제하고 `padding:12px 15px`로 상하 균형을 잡았습니다. 모바일에서도 비슷한 패딩을 유지합니다.
4. **세 가지 경험의 번호와 간격**: 01/02/03을 산세리프 일반체(기울임 0)로 변경했습니다. LEADERSHIP/RESEARCH/CURIOSITY 레이블과 본문 제목 간격은 13px에서 5px로 좁혔습니다. 워드마크의 장식적인 Georgia도 산세리프로 변경했습니다.
5. **세 가지 경험의 본문 제목**: T01의 원본 `<br>`는 건드리지 않고, T08 공개 복제본에서 3개 제목의 강제 줄바꿈을 제거합니다. 텍스트 내용은 유지되며 화면 폭이 좁을 때만 브라우저가 자연스럽게 줄바꿈합니다.
