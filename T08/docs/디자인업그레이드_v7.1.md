# T08 v7.1 — 경험 상세 폭 개선

- 원인: `.story`가 `strength-detail` 우측 열 안에 중첩되어 있어, 펼쳐도 폭이 약 200–300px로 제한되었습니다.
- 처리: 화면 진입 후 `design-motion.js`가 각 `.story`를 해당 `.strength`의 직접 자식으로 이동합니다. 원본 T01 HTML 및 기존 `script.js`는 수정하지 않습니다.
- 데스크톱: 제목/접기 버튼의 위치는 유지하고, 펼친 설명은 **가운데 열과 오른쪽 열을 함께 사용**합니다. 상황·행동은 두 열, 결과는 전체 너비로 표시합니다.
- 모바일: 한 열로 이어 읽도록 표시합니다.
- 기존 패스키 API/권한/비공개 데이터는 건드리지 않습니다.
- 배포 전 `npm run sync:t01`, `npm run build`, `npm test`를 실행하세요.
