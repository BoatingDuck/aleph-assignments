# 가을의 온도 · T04

대전 관측소의 실제 기온을 조회하고 날짜별로 기록하는 정보판이다. 관측소 측정값이므로 대전 전체의 온도가 같다는 뜻은 아니다.

## 실제 기온 기록

- 출처: 기상청 날씨누리 도시별 기상실황표, 대전 관측소(133)
- 화면에는 기상청 관측 시각과 앱의 조회 시각을 따로 표시한다.
- 날짜는 `Asia/Seoul` 기준으로 정한다. 같은 날 다시 조회하면 그 날짜의 기록을 갱신하고, 기록을 확정하면 더 이상 덮어쓰지 않는다.
- 원자료, 일별 저장값, 화면 표시값을 기록 상세에서 대조할 수 있다.
- 실제 기록은 최대 두 날짜까지 저장한다. 합성 시험 기록은 실제 기록과 분리한다.

## 데이터가 오지 않을 때

실패 재생실에서 응답 지연, 원천의 401/403 거절, 호출 제한, 오프라인, 응답 형식 변경을 각각 시험할 수 있다. 실패가 나면 마지막 정상값을 보존하고, 오래된 값 상태와 실패 종류, 다시 시도 안내를 보여 준다. 복구 버튼은 합성 D2 fixture를 재생한다.

합성 시험값은 시험 화면에서만 사용하며 실제 날씨 기록으로 저장하지 않는다. 공개 fixture 17개의 SHA-256은 `public/t04-assets/asset-manifest.json`에 기록되어 있다. 판정 계약 ID는 `aleph-t04-real-information-board-public-contract-v2`이다.

## 보안과 데이터 보관

브라우저는 기상청을 직접 호출하지 않는다. 서버가 비밀키가 필요 없는 공개 자료를 조회한다. 원천 응답 형식이 바뀌거나 관측 시각이 2시간보다 오래되면 새 정상 기록으로 저장하지 않고 마지막 정상값을 유지한다.

Vercel 배포는 Neon Postgres에 기록을 보관한다. 연결 문자열은 서버 환경변수 `DATABASE_URL`로만 읽는다. Vercel DB는 기존 Site의 D1 DB와 별개이므로, 실제 기록을 옮기는 절차는 [VERCEL_DEPLOY.md](./VERCEL_DEPLOY.md)에 적었다. 실제 기록 JSON과 `.env.local`은 GitHub에 올리지 않는다.
