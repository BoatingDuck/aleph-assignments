# T03 — 짤·카드 스튜디오

<br>

## 목표

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 PNG 파일로 내려받을 수 있는 웹 편집기를 구현한다.

PNG·JPEG 이미지 처리, 세 가지 화면비, 템플릿 관리, JSON 복원, 극단 입력 검사까지 완료하는 것을 목표로 한다.

<br>

## 구현 순서

### 1. 기본 편집기
- [ ] PNG 이미지 불러오기
- [ ] JPEG 이미지 불러오기
- [ ] 지원하지 않는 파일 거부
- [ ] 잘못된 파일을 넣어도 기존 작업 유지
- [ ] 거부 이유 표시
- [ ] 문구 입력
- [ ] 문구 위치 변경
- [ ] 문구 크기 변경
- [ ] 문구 색상 변경
- [ ] 변경 내용 즉시 미리보기 반영

### 2. 화면비와 다운로드
- [ ] 1:1 지원
- [ ] 4:5 지원
- [ ] 9:16 지원
- [ ] PNG 다운로드
- [ ] 미리보기와 다운로드 이미지의 잘림 일치
- [ ] 문구 위치 일치
- [ ] 줄바꿈 일치

### 3. 템플릿 관리
- [ ] 템플릿 이름 지정
- [ ] 템플릿 생성
- [ ] 템플릿 3개 이상 생성
- [ ] 템플릿 불러오기
- [ ] 템플릿 수정
- [ ] 템플릿 삭제
- [ ] 새로고침 후 데이터 유지
- [ ] 템플릿마다 고유 ID 사용

### 4. JSON 가져오기·내보내기
- [ ] 템플릿 JSON 내보내기
- [ ] 정상 JSON 가져오기
- [ ] 손상된 JSON 거부
- [ ] 필수 항목이 없는 JSON 거부
- [ ] 잘못된 JSON 입력 시 기존 데이터 유지

### 5. 극단 입력 검사
- [ ] 극단 입력 12건 작성
- [ ] 긴 한글
- [ ] 긴 영문
- [ ] 한글·영문 혼합
- [ ] 직접 줄바꿈
- [ ] 이모지
- [ ] 빈 문구
- [ ] 세로 이미지
- [ ] 가로 이미지
- [ ] 투명 이미지
- [ ] 기타 극단 입력
- [ ] 수정 전 FAIL 1건 이상 기록
- [ ] 동일 입력 수정 후 PASS 기록

### 6. 완성본 검사
- [ ] 서로 다른 문구 또는 화면비의 완성 이미지 3개 생성
- [ ] 완성 이미지 3개 정상 열림 확인
- [ ] 이미지 사용 권한 기록
- [ ] 위치 정보 메타데이터 확인
- [ ] 개인정보 0건 확인
- [ ] 비밀값 원문 0건 확인

### 7. 배포 및 제출
- [ ] 공개 배포
- [ ] 시크릿 창에서 결과물 주소 확인
- [ ] 시크릿 창에서 소스 주소 확인
- [ ] 로그인 없이 접근 가능한지 확인
- [ ] 짧은 확인 방법 4줄 작성
- [ ] AI와 나의 판단 3줄 작성

<br>

## 개발 원칙

- 미리보기와 다운로드는 가능한 한 같은 Canvas 렌더링 로직을 사용
- 잘못된 파일이나 JSON은 검증이 끝난 뒤에만 현재 상태에 적용
- 오류가 발생하더라도 기존 편집 내용과 템플릿은 유지
- 템플릿 식별에는 배열 순서가 아닌 고유 ID를 사용
- 테스트 과정에서 실제로 발견한 결함과 수정 결과를 기록
