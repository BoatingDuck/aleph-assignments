# T05 카드 스튜디오 Undo/Redo 인수인계 문서

## ① 목표

기존 T03 기반 카드 스튜디오의 기능과 UI를 최대한 유지하면서 Undo(실행 취소) / Redo(다시 실행) 기능을 추가하는 것이 목표였다.

`T05-SPEC.md`의 요구사항에 따라 다음 편집 상태의 변경을 Undo/Redo할 수 있어야 한다.

- 문구
- 문구 위치
- 문구 색상
- 화면비
- 템플릿 적용
- 기타 기존 편집 상태 변경

Undo 이후 새로운 편집이 발생하면 기존 Redo 이력은 제거되어야 한다.

페이지를 새로고침하면 이전 실행의 Undo/Redo 이력이 남지 않아야 한다.

작업 시작 전에 고정된 검사 10개는 삭제·완화하거나 기대값을 변경하지 않고 그대로 사용해야 한다.

- 기존 T03의 다운로드 history 기능과 편집 Undo/Redo history를 분리

## ③ 실행 명령

현재 프로젝트는 별도 npm 실행 환경이 아니라 `src/index.html`을 브라우저에서 직접 열어 실행하는 구조다.

전달받은 프로젝트를 압축 해제한 뒤 다음 파일을 브라우저에서 직접 연다.


## ⑤ 남은 문제

### 1. T05-TEST-10 사용자 직접 검증 필요

현재 사용자가 직접 확인한 것은 T05-TEST-01 ~ T05-TEST-09까지다.

AI B는 반드시 **T05-TEST-01부터 T05-TEST-10까지 동일한 고정 검사 10개를 변경 없이 그대로 실행**해야 한다.

특히 T05-TEST-10은 아직 사용자 직접 검증 전이다.

### 2. 검사 기록 파일의 ZIP 포함 여부 확인 필요

이전 응답에서 다음 두 파일이 존재한다고 안내했지만, **전달된 ZIP에 실제로 포함되어 있는지는 아직 확인되지 않았다.**

```text
tests/t05-undo-redo-tests.md
tests/t03-regression-results.md
```

AI B는 전달받은 ZIP의 실제 파일 목록을 확인해야 한다.

파일이 없다면 이를 남은 문제로 처리하고, 필요한 경우 검사 결과를 정확하게 기록해야 한다.

### 3. 최종 ZIP의 무결성 확인 필요

이전에 다운로드 링크 문제가 발생했으므로, AI B는 최종 완료 시 다음을 확인해야 한다.

- ZIP이 실제로 생성되어 있는지
- ZIP 압축 해제가 정상적으로 되는지
- 필요한 프로젝트 파일이 모두 들어 있는지
- T05 관련 파일과 검사 파일이 누락되지 않았는지

## ⑥ 다음 행동

AI B는 다음 순서로 작업한다.

1. 전달받은 ZIP을 압축 해제한다.
2. 프로젝트 구조와 `T05-SPEC.md`를 확인한다.
3. 기존 T03 기반 기능이 유지되어 있는지 확인한다.
4. `tests/t05-undo-redo-tests.md`와 `tests/t03-regression-results.md`가 실제 ZIP에 존재하는지 확인한다.
5. 고정 검사 10개를 **수정 없이 원본 그대로** 실행한다.
6. T05-TEST-01 ~ T05-TEST-10의 결과를 각각 기록한다.
7. T05-TEST-10을 반드시 별도로 확인한다.
8. 검사 중 발견되는 실제 문제만 수정한다.
9. 수정 후 고정 검사 10개를 다시 전부 실행한다.
10. 기존 T03 기반 기능의 회귀 여부를 다시 확인한다.
11. 최종 ZIP을 새로 만들고 압축 해제가 정상적으로 되는지 확인한다.
12. 최종 결과에는 고정 검사 10개의 개별 PASS/FAIL 결과를 명확하게 남긴다.

**중요:** 필요한 경우 남은 문제를 수정하는 것은 AI B의 책임이지만, 고정 검사 10개의 내용·기대값·조건 자체를 변경해서는 안 된다.

## ⑦ 건드리지 말 것

다음 사항은 AI B가 임의로 변경하지 않는다.

- `T05-SPEC.md`
- 고정 검사 T05-TEST-01 ~ T05-TEST-10의 내용
- 고정 검사 10개의 기대값
- 기존 T03 기반 기능
- 기존 카드 스튜디오 UI의 불필요한 변경
- 기존 다운로드 history 기능
- 기존 기능을 대체하기 위한 별도의 대규모 리팩터링
- 검사 통과를 위해 테스트를 삭제하거나 완화하는 행위
- 검사 결과를 실제 확인 없이 PASS로 기록하는 행위
- Undo/Redo 이력을 새로고침 이후에도 유지하도록 만드는 변경
- Undo 후 새로운 편집이 발생했는데 Redo 이력이 남도록 만드는 변경

특히 **고정 검사 10개를 통과시키기 위해 테스트 자체를 수정해서는 안 된다.**
