# T03 극단 입력 12건 검사 기록

실제 실행 뒤 `실제 결과`와 `PASS/FAIL`을 채운다. 결과를 미리 만들어 적지 않는다.

| 번호 | 검사 입력 | 예상값 | 실제 결과 | 판정 |
|---|---|---|---|---|
| 1 | 긴 한글 문장 300자 이상 | 폭에 맞게 줄바꿈되고 편집 상태가 유지됨 |  |  |
| 2 | 긴 영문 문장 | 폭에 맞게 줄바꿈되고 저장 가능 |  |  |
| 3 | 한글+영문+숫자 혼합 | 문자 종류와 관계없이 표시됨 |  |  |
| 4 | 직접 줄바꿈 4줄 이상 | 입력한 줄바꿈이 유지됨 |  |  |
| 5 | 이모지 포함 문구 | 가능한 글꼴로 표시되고 앱이 멈추지 않음 |  |  |
| 6 | 빈 문구 | 이미지 편집 상태는 유지되고 저장 가능 |  |  |
| 7 | 공백 없는 매우 긴 문자열 | 글자 단위로 안전하게 줄바꿈됨 |  |  |
| 8 | 세로 이미지 | 선택 화면비에 cover 방식으로 표시됨 |  |  |
| 9 | 가로 이미지 | 선택 화면비에 cover 방식으로 표시됨 |  |  |
| 10 | 투명 PNG | 투명 영역을 포함해 정상 표시됨 |  |  |
| 11 | 지원하지 않는 파일 | 거부 이유가 표시되고 기존 편집 내용 유지 |  |  |
| 12 | 매우 작은 이미지 / 극단 위치 | 앱 오류 없이 미리보기·다운로드 가능 |  |  |
