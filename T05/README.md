# T03 — 짤·카드 스튜디오

이미지와 문구를 조합해 밈·카드·SNS 게시용 이미지를 만들고 PNG로 내려받는 공개 편집기이다.

## 실행

`src/index.html`을 브라우저에서 열어도 동작한다. 실제 제출에서는 정적 호스팅(Vercel 등)에 `src` 폴더를 배포한다.

## 구현된 핵심 기능

- PNG·JPEG 업로드
- 지원하지 않는 파일 거부 + 기존 편집 상태 유지
- 한글 문구 위치·크기·색상 즉시 반영
- 1:1 / 4:5 / 9:16 화면비
- 같은 Canvas를 이용한 미리보기·PNG 다운로드
- 템플릿 생성·불러오기·수정·삭제
- localStorage 기반 새로고침 유지
- 고유 ID 기반 템플릿 관리
- JSON 내보내기 / 정상 JSON 복원
- 손상 JSON / 필수 항목 누락 JSON 전체 검증 후 거부
- 이미지 재합성을 통한 메타데이터 제거
- 이미지 사용 권한 기록
- 다운로드 결과 기록 보관

## 폴더

- `src/` 웹 소스
- `assets/` 테스트 이미지와 잘못된 파일
- `tests/` 실제 검사 기록용 문서
- `samples/` JSON 검사 샘플
- `outputs/` 완성 이미지 3개를 직접 내려받아 보관
- `SUBMISSION.md` 최종 제출문 초안

## 주의

테스트 문서의 PASS/FAIL은 실제 실행 후 직접 기록한다.  
특히 C15는 개발 과정에서 실제로 발견한 동일 입력의 FAIL → 수정 → PASS를 남긴다.
