# T05 비교 기록

## 작업 개요

- 기존 T03 카드 스튜디오는 그대로 두고, T05 작업본에서 Undo / Redo 기능을 추가했다.
- 이번 작업은 한 번에 끝내지 않고 두 번의 AI 작업으로 나눴다.
- 도구 X가 먼저 기능을 구현하고 인수인계 문서를 남겼고, 도구 Y는 이전 대화 내용 없이 저장소와 인수인계 문서만 보고 이어서 작업했다.

<br>

## 작업 전에 정한 조건

두 도구 모두 같은 조건으로 진행했고, 작업 중 고정 검사 삭제, 완화, 기대값 변경은 하지 않았다.

| 항목 | 공통 조건 |
| --- | --- |
| 작업 시간 상한 | 30분 |
| 요청·호출 상한 | 8회 |
| 고정 검사 수 | 10개 |
- 검사 삭제: 0건
- 검사 완화: 0건
- 기대값 변경: 0건

## 고정 검사 10개

| ID | 입력 | 관찰 가능한 기대값 |
| --- | --- | --- |
| T05-TEST-01 | 문구를 `T05-원본`으로 붙여넣고, 이어 `T05-수정`으로 붙여넣은 뒤 Undo 1회 | 문구 입력란과 미리보기가 모두 `T05-원본`으로 돌아간다. |
| T05-TEST-02 | T05-TEST-01 직후 Redo 1회 | 문구 입력란과 미리보기가 다시 `T05-수정`이 된다. |
| T05-TEST-03 | 문구를 `T05-A` → `T05-B` → `T05-C` 순서로 각각 붙여넣은 뒤 Undo 2회 | 문구 입력란과 미리보기가 `T05-A`로 돌아간다. |
| T05-TEST-04 | T05-TEST-03 직후 Redo 2회 | 문구 입력란과 미리보기가 `T05-C`가 된다. |
| T05-TEST-05 | `T05-A` → `T05-B`로 변경 → Undo 1회 → `T05-새편집` 붙여넣기 | `T05-새편집`이 유지되고 Redo를 실행할 수 없는 상태가 된다. 이전 `T05-B`가 다시 나타나지 않는다. |
| T05-TEST-06 | 문구를 `T05-텍스트`로 설정 → 문구를 완전히 비움 → Undo 1회 | 문구 입력란과 미리보기에 `T05-텍스트`가 복원된다. |
| T05-TEST-07 | 가로 위치 50% 상태에서 가로 위치 슬라이더에 포커스 → 오른쪽 방향키 1회 → Undo 1회 | 가로 위치가 51%로 변경된 뒤 Undo 후 다시 50%가 되고 미리보기 위치도 복원된다. |
| T05-TEST-08 | 화면비 `1:1` → `9:16` 변경 → Undo 1회 | 선택 화면비와 미리보기가 다시 `1:1`로 돌아간다. |
| T05-TEST-09 | 직접 편집한 상태에서 미리 저장한 템플릿을 `불러오기` → Undo 1회 | 템플릿을 불러오기 직전의 직접 편집 상태가 한 번에 복원된다. |
| T05-TEST-10 | 편집 상태를 한 번 변경하여 Undo 가능 상태를 만든 뒤 페이지 새로고침 | 새로고침 전 Undo/Redo 이력이 남지 않으며 Undo와 Redo를 실행할 수 없는 상태가 된다. |

## 작업 순서

> 
> 
> 
> 도구 X 시작 → 도구 X 종료 및 인수인계 → 도구 Y 시작 → 도구 Y 종료
> 

도구 X는 Undo / Redo 기능을 구현했다.

인계 시점에는 T05-TEST-01부터 09까지 직접 확인했고 모두 PASS으며, T05-TEST-10은 아직 확인하지 않은 상태로 넘겼다.

인수인계 문서에는 다음 7가지를 적었다.

1. 목표
2. 현재 상태
3. 실행 명령
4. 통과 검사
5. 남은 문제
6. 다음 행동
7. 건드리지 말 것

도구 Y에는 이전 대화 전문을 주지 않고 저장소와 이 인수인계 문서만 전달했다.
