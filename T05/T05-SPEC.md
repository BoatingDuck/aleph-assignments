# T05 실험 규칙 — 시작 전 고정본

## 1. 개선 목표

T03 카드 스튜디오의 기존 기능과 UI를 최대한 유지하면서 **실행 취소(Undo) / 다시 실행(Redo)** 기능을 추가한다.

Undo/Redo 대상은 편집 화면의 상태 변경이다. 주요 대상은 문구, 문구 위치, 문구 색상, 화면비, 템플릿 불러오기 등이다.

템플릿 생성·삭제, JSON 내보내기 같은 관리 기능 자체는 Undo/Redo 대상에 포함하지 않는다.

---

## 2. 공통 사용 상한

AI A와 AI B에 동일하게 적용한다.

- 시간 상한: **30분**
- 요청·호출 수 상한: **8회**

두 값은 최대 허용량이며 반드시 전부 사용할 필요는 없다.

---

## 3. AI A와 AI B에 사용할 동일 최초 요청

기존 T03 이미지 편집기에 실행 취소(Undo)와 다시 실행(Redo) 기능을 추가해 주세요. 기존 기능과 UI는 최대한 유지하고, 문구·문구 위치·문구 색상·화면비·템플릿 적용 등 편집 상태 변경을 Undo/Redo할 수 있어야 합니다. Undo 후 새로운 편집이 발생하면 기존 Redo 이력은 제거하고, 페이지를 새로고침하면 이전 실행의 Undo/Redo 이력은 남기지 않습니다. 시작 전에 고정한 검사 10개는 삭제·완화하거나 기대값을 변경하지 말고 그대로 사용해 주세요. 작업 중 검사 결과를 기록하고 기존 T03 기능이 깨지지 않도록 구현해 주세요.

---

## 4. 고정 검사 10개

아래 10개 검사는 AI A 작업 시작 전에 고정한다. 이후 검사 삭제, 완화, 기대값 변경을 하지 않는다.

| ID | 입력 | 관찰 가능한 기대값 |
|---|---|---|
| T05-TEST-01 | 문구를 `T05-원본`으로 붙여넣고, 이어 `T05-수정`으로 붙여넣은 뒤 Undo 1회 | 문구 입력란과 미리보기가 모두 `T05-원본`으로 돌아간다. |
| T05-TEST-02 | T05-TEST-01 직후 Redo 1회 | 문구 입력란과 미리보기가 다시 `T05-수정`이 된다. |
| T05-TEST-03 | 문구를 `T05-A` → `T05-B` → `T05-C` 순서로 각각 붙여넣은 뒤 Undo 2회 | 문구 입력란과 미리보기가 `T05-A`로 돌아간다. |
| T05-TEST-04 | T05-TEST-03 직후 Redo 2회 | 문구 입력란과 미리보기가 `T05-C`가 된다. |
| T05-TEST-05 | `T05-A` → `T05-B`로 변경 → Undo 1회 → `T05-새편집` 붙여넣기 | `T05-새편집`이 유지되고 Redo를 실행할 수 없는 상태가 된다. 이전 `T05-B`가 다시 나타나지 않는다. |
| T05-TEST-06 | 문구를 `T05-텍스트`로 설정 → 문구를 완전히 비움 → Undo 1회 | 문구 입력란과 미리보기에 `T05-텍스트`가 복원된다. |
| T05-TEST-07 | 가로 위치 50% 상태에서 가로 위치 슬라이더에 포커스 → 오른쪽 방향키 1회 → Undo 1회 | 가로 위치가 51%로 변경된 뒤 Undo 후 다시 50%가 되고 미리보기 위치도 복원된다. |
| T05-TEST-08 | 화면비 `1:1` → `9:16` 변경 → Undo 1회 | 선택 화면비와 미리보기가 다시 `1:1`로 돌아간다. |
| T05-TEST-09 | 직접 편집한 상태에서 미리 저장한 템플릿을 `불러오기` → Undo 1회 | 템플릿을 불러오기 직전의 직접 편집 상태가 한 번에 복원된다. |
| T05-TEST-10 | 편집 상태를 한 번 변경하여 Undo 가능 상태를 만든 뒤 페이지 새로고침 | 새로고침 전 Undo/Redo 이력이 남지 않으며 Undo와 Redo를 실행할 수 없는 상태가 된다. |

## 5. 검사 실행 규칙

- 텍스트 값 변경 검사는 직접 한 글자씩 입력하기보다 전체 값을 붙여넣어 한 번의 명확한 변경으로 실행한다.
- T05-TEST-07은 마우스로 슬라이더를 끌지 않고 오른쪽 방향키를 정확히 1회 사용한다.
- T05-TEST-09 실행 전 테스트용 템플릿 하나를 미리 저장해 둔다.
- 각 AI는 동일한 10개 검사를 사용한다.
- FAIL이 발생해도 검사를 삭제하거나 기대값을 낮추지 않는다.
- 오류 회차는 고정 검사 10개를 한 번 실행한 회차 중 하나 이상의 FAIL이 나온 회차로 센다.

---

## 6. 버전 보존 규칙

- 기존 `T03` 폴더는 기존 제출본이므로 수정하지 않는다.
- T05 작업은 T03 최종본을 복사한 `T05` 폴더에서만 수행한다.
- A 시작, A 종료·인수인계, B 시작, B 종료의 각 소스 버전을 Git commit으로 보존한다.
- B 시작 소스는 A 종료·인수인계 시점의 소스와 같아야 한다.
