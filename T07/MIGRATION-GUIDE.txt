T07 4단계 — 최종 T06 데이터 T07 내 계정으로 이전

목적
- T06 원본 Neon DB는 절대 수정하지 않는다.
- T06의 기존 Plan/Do/See 자료를 T07 Neon DB로 복사한다.
- 복사된 최상위 plans와 security_checks를 T07의 "내 계정" user_id에 연결한다.
- T07-C100 증거로 원본/복사 수량을 비교한 JSON 보고서를 만든다.

1. 파일 추가
   scripts/migrate-t06-data.mjs

2. T07/.env.local에 아래 두 줄이 모두 있어야 한다.

   DATABASE_URL="T07 Neon pooled connection string"
   T06_DATABASE_URL="T06 Neon pooled connection string"

   주의:
   - 두 URL은 서로 달라야 한다.
   - 실제 값은 GitHub/제출물/대화에 올리지 않는다.
   - .env.local은 .gitignore 대상이어야 한다.

3. T07에서 "내 자료의 주인"으로 사용할 계정의 로그인 아이디를 정한다.
   A/B 테스트 계정 중 실제로 계속 쓸 계정을 선택해도 된다.
   비밀번호는 명령어에 넣지 않는다.

4. 실행
   T07 폴더에서:

   node scripts/migrate-t06-data.mjs "내_로그인아이디"

5. 성공 예시

   === T06 → T07 이전 결과 ===
   plans: 1/1
   planVersions: 1/1
   tasks: 6/6
   idempotencyKeys: 5/5
   completions: 5/5
   executions: 3/3
   reflections: 1/1
   securityChecks: 1/1

   T06 기존 자료 이전 완료
   보고서: T07-T06-MIGRATION-REPORT.json

   실제 숫자는 T06 DB 내용에 따라 달라도 된다.
   핵심은 각 항목 matched/source가 서로 같아야 한다.

6. 성공 뒤 브라우저 확인
   - 선택한 내 계정으로 로그인
   - 기존 T06 계획/할 일/실행 기록/돌아보기 값이 보이는지 확인
   - 테스트용 다른 계정으로 로그인
   - 그 계정에는 T06 기존 자료가 보이지 않는지 확인

7. 보안
   이전 완료 후 .env.local에서 T06_DATABASE_URL은 삭제해도 된다.
   T07-T06-MIGRATION-REPORT.json에는 비밀번호/세션/DB URL이 기록되지 않는다.

8. Git
   migrate-t06-data.mjs와 안전한 보고서는 커밋 가능하다.
   .env.local은 절대 커밋하지 않는다.
