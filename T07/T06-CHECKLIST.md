# T06 최종 수동 검수표

- [ ] 시크릿 창에서 결과물 URL이 로그인 없이 열린다. (C01)
- [ ] 첫 화면에 공개 안내 문구가 보인다. (C82)
- [ ] 실제 계획 1개 이상이 저장되어 있다. (C78)
- [ ] 계획 기간/우선순위/성공 기준/예상 시간이 저장된다. (C04~C07)
- [ ] 계획을 수정한 뒤 이전 계획이 수정 이력에 남는다. (C08)
- [ ] 선택 계획에 실제 할 일 5개 이상이 있다. (C79)
- [ ] 할 일 생성/수정/완료/되돌리기/삭제가 된다. (C09~C13)
- [ ] 마감일/우선순위/태그/예상 시간이 저장된다. (C14~C17)
- [ ] 검색/필터/정렬이 화면에 적힌 기준대로 동작한다. (C18~C20)
- [ ] 실제 실행 기록 3개 이상이 있다. (C80)
- [ ] 시작/끝/실제 분/막힌 이유가 저장된다. (C23~C26)
- [ ] 실행 기록을 넣어도 원래 계획/예상 시간이 변하지 않는다. (C27)
- [ ] 완료 버튼을 빠르게 두 번 눌러 완료 기록이 한 건만 생긴다. (C21)
- [ ] 같은 시험에서 완료 집계도 1만 증가한다. (C22)
- [ ] 계획/완료/지연/막힘/예상/실제/차이 집계가 맞다. (C28~C32)
- [ ] 집계 숫자를 누르면 해당 근거 기록으로 이동한다. (C83)
- [ ] 고칠 점 한 줄이 다음 계획의 `이전 계획에서 넘어온 고칠 점`으로 보인다. (C33)
- [ ] 돌아보기 숫자가 모두 0이 아니다. (C81)
- [ ] 새로고침 후 ID/날짜/값/분 단위가 그대로다. (C34~C35)
- [ ] 전체 자료 JSON 파일이 내려받아진다. (C36)
- [ ] `<script>alert('xss')</script>`를 저장해도 실행되지 않고 문자 그대로 보인다. (C57)
- [ ] `npm run security:scan` 결과가 0건이다. (C58 보조검사)
- [ ] Network/Console/Git history에도 DB URL/비밀값 원문이 없다. (C58)
- [ ] `contracts/pds-schema-v2.json`이 최종 Git 소스에 있다.
