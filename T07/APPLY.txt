[사전 확인]
1) package.json 이름이 t07-plan-do-see-diary인지 확인
2) bcryptjs 설치 여부:
   npm.cmd install bcryptjs
3) .env.local에 T07 Neon DATABASE_URL이 있는지 확인

[실행]
npm.cmd run dev

브라우저:
http://localhost:3000

[이번 단계에서 확인할 것]
1) 첫 화면이 로그인 화면이다.
2) '가입' 탭에서 계정을 만들 수 있다.
3) 같은 아이디로 다시 가입하면 '이미 사용 중인 아이디입니다.'가 나온다.
4) 가입한 계정으로 로그인하면 기존 PlannerApp 화면이 열린다.
5) 오른쪽 위 로그아웃 버튼을 누르면 다시 로그인 화면이 나온다.
6) 로그인 후 /api/auth/me 는 200, 로그아웃 후 /api/auth/me 는 401이다.
7) 없는 아이디 로그인과 틀린 비밀번호 로그인은 둘 다
   '아이디 또는 비밀번호가 올바르지 않습니다.'로 동일하다.

[중요]
- 이번 단계만으로 T07 보안 조건이 끝난 것이 아니다.
- 기존 /api/plans, /api/tasks 등 T06 자료 API는 아직 사용자 소유권 검사를 붙이지 않았다.
- 따라서 아직 Vercel 최종 배포/제출 상태로 간주하지 않는다.
- 다음 단계에서 기존 모든 자료 API에 로그인 검사 + user_id 소유권 검사를 붙인다.
