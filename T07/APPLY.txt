[이 단계가 하는 일]
- 모든 기존 자료 API에서 먼저 현재 세션 사용자를 확인한다.
- 로그인하지 않으면 401을 반환한다.
- 계획 목록은 plans.user_id = 현재 사용자만 반환한다.
- 계획 상세/수정/삭제는 현재 사용자 소유 계획만 허용한다.
- 할 일/실행 기록/돌아보기는 plan → user 소유권까지 JOIN해서 검사한다.
- 클라이언트가 URL/헤더/본문에 다른 user id를 넣어도 소유자 판단에는 사용하지 않는다.
- 다른 사용자 자료 ID를 직접 넣은 읽기/수정/삭제 요청은 404로 처리해 존재 자체를 숨긴다.
- export는 현재 사용자 자료만 포함하며 password_hash/sessions는 절대 내보내지 않는다.

[중요]
- 지금 새 T07 Neon DB는 T06 기존 데이터 복사가 아직 안 됐다면 기존 T06 자료가 보이지 않는 것이 정상이다.
- T07-C100 때문에 나중에 최종 T06 자료를 T07 DB로 복사한 뒤 네 계정 user_id에 연결해야 한다.
- 이 파일 적용 후부터 새로 만드는 계획에는 user_id가 자동으로 현재 로그인 계정으로 저장된다.

[적용 뒤 기본 기능 확인]
1) 로그인 후 새 계획 1개 생성
2) 그 계획 안에 할 일 1개 생성
3) 새로고침 후 그대로 보이는지 확인
4) 로그아웃
5) 브라우저 주소창에 아래 입력:
   http://localhost:3000/api/plans
   → {"ok":false,"error":"로그인이 필요합니다."} / HTTP 401이어야 함
6) 다시 로그인
7) 계획/할 일 생성·수정·완료·되돌리기·삭제, 실행 기록, 돌아보기, 내보내기가 기존처럼 동작하는지 확인
